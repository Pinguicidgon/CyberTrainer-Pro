# CyberTrainer Pro

Simulador de ciberseguridad orientado a formación empresarial.

## Funcionalidades

- Panel principal con métricas
- Evaluación de contraseñas
- Simulación de phishing
- Historial de resultados
- Informe final con recomendaciones
- Rankings entre usuarios

## Instalación

```bash
pip install -r requirements.txt
python app.py
```

## Acceso

Abrir en el navegador:

http://127.0.0.1:5000
